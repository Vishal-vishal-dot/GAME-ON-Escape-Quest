# 🎮 GAME ON! – 4-Hour Game Quest

**“No Experience. Just Play, Build & Win.”**

Welcome to **GAME ON!**, a beginner-friendly 4-hour Game Development Workshop + Challenge using **GDevelop**.

This repository contains the **GDevelop starter project** that participants will use during the workshop. The starter game is already prepared with basic gameplay, and participants will enhance it by completing missions, challenges, and adding their own creative ideas.

## 📦 Starter Project

The starter project is provided as a ZIP file:

**`GameQuest_Starter.zip`**

The ZIP contains the complete GDevelop project required for the workshop.

## 🛠️ How to Get Started

1. Download **`GameQuest_Starter.zip`** from this repository.
2. Extract the ZIP file on your computer.
3. Open **GDevelop**.
4. Select **Open a project**.
5. Navigate to the extracted `GameQuest_Starter` folder.
6. Open the GDevelop project file.
7. Run the game and explore the existing gameplay.
8. Start modifying and enhancing the game according to the workshop challenges.

> ⚠️ **Important:** Extract the ZIP file before opening the project. Do not edit the project directly inside the ZIP file.
