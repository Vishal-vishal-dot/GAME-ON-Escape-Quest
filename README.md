# 🎮 GAME ON! – 4-Hour Game Quest

**“No Experience. Just Play, Build & Win.”**

Welcome to **GAME ON!**, a beginner-friendly 4-hour Game Development Workshop + Challenge using **GDevelop**.

This repository contains **two GDevelop game projects** that participants can download, open, edit, and enhance during the workshop.

---

## 📦 Game Projects

The projects are provided as ZIP files:

### 🎮 Game Quest 1

**`GAME ON! – 4-Hour Game Quest 1.zip`**

This ZIP contains a complete GDevelop project with:

- `game.json`
- `assets` folder

### 🎮 Game Quest 2

**`GAME ON! – 4-Hour Game Quest 2.zip`**

This ZIP contains a complete GDevelop project with:

- `GAME-ON-Escape-Quest.json`
- `assets` folder

Participants can choose the project provided for their challenge and start modifying it.

---

## 🛠️ How to Get Started

1. Download the required ZIP file from this repository.
2. Extract the ZIP file on your computer.
3. Open **GDevelop**.
4. Select **Open a project**.
5. Navigate to the extracted project folder.
6. Open the GDevelop project file:

   - For **Game Quest 1**, open `game.json`
   - For **Game Quest 2**, open `GAME-ON-Escape-Quest.json`

7. Run the game and explore the existing gameplay.
8. Start modifying and enhancing the game according to the workshop challenges.

> ⚠️ **Important:** Extract the ZIP file before opening the project. Do not edit the project directly inside the ZIP file.
